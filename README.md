# Night Survivors

A tiny **2-minute survivors game** made for CDT501 Lecture 9 (Digital Media).
You only walk; your weapons attack by themselves. Survive until 2:00.

**Play:** https://wgawga041815-create.github.io/night-survivors/

> First visit downloads about 11 MB of Python/pygame runtime. On a phone it can take
> 30–60 seconds; later visits are cached. Tap once to start.

## Controls

- **Computer:** move toward the mouse pointer; the hero keeps walking while the pointer is away.
- **Phone:** hold a finger on the screen to walk; lift it to stop.
- **P:** pause. **M:** mute.
- Level up: click/tap one of the three cards.
- End screen: click/tap to play again.

## Rules (from `GAME.md`)

- Survive 2:00 → VICTORY; HP 0 → GAME OVER.
- Spark Wand, Spin Blades and Holy Ring; three weapons maximum, levels 1–5.
- Swift Boots, Big Heart and Magnet; five levels each.
- Bats, Slimes, Ghosts and a Demon boss at 1:30. The wave table is in `data/game.json`.
- All tuning numbers live in `data/game.json`; no code change is needed to change a number.

## Run locally

```bash
python -m pip install pygame-ce pillow soundfile pygbag
python make_assets.py        # raw_art/ -> assets/ (Pillow)
python make_sounds.py        # sounds/*.wav (standard library)
python convert_sounds.py     # sounds/*.ogg (soundfile; pygbag prefers OGG)
python main.py
```

Tests for the rules only (no pygame):

```bash
python -m unittest discover -s tests -v
```

## Build the web version

```bash
python make_web.py
```

This stages only the runtime files, runs pygbag, copies `build/web` to `docs/`,
adds `.nojekyll`, and applies the dark loading page. GitHub Pages serves `docs/`.

## Files

- `rules.py` — the whole simulation, no pygame, fixed 1/60 s step.
- `main.py` — pygame-ce window, drawing, sound and input; async loop for pygbag.
- `data/game.json` — every number from `GAME.md`.
- `make_assets.py` — 3× nearest-neighbour copies and blue/pink crystals.
- `make_sounds.py` — short sounds with `math`, `wave` and `struct`.
- `make_web.py` — pygbag build → `docs/`.
- `tests/` — unittest tests for spawning, damage, XP, cards, win/lose.
- `raw_art/` — Kenney.nl art (CC0), never modified.
- `assets/fonts/` — DejaVu Sans (free licence included).
